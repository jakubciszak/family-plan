# Family Plan - Live Demo

🚀 **[Otwórz Live Demo](https://jakubciszak.github.io/family-plan/)**

## O Prototypie

To jest w pełni funkcjonalny prototyp aplikacji Family Plan - systemu zarządzania zadaniami domowymi dla rodziny z gamifikacją i systemem punktów.

## Jak Używać

1. Otwórz demo w przeglądarce
2. Zaloguj się używając jednego z kont testowych:

### Konta Demo

**Administrator:**
```
Email: admin@family.com
Hasło: admin
```

**Użytkownik (dziecko):**
```
Email: child1@family.com
Hasło: child1
```

**Inne dostępne konta:**
- `parent@family.com` / `parent` (Admin)
- `child2@family.com` / `child2` (User)
- `user@family.com` / `user` (User)

## Funkcje

### ✅ Dla wszystkich użytkowników:
- Lista zadań z filtrowaniem
- Wykonywanie przypisanych zadań
- System punktów
- Przeglądanie zespołów
- Ustawienia profilu
- Wielojęzyczność (PL/EN)

### 👑 Dla administratorów:
- Tworzenie zadań
- Przypisywanie zadań do użytkowników
- Zatwierdzanie wykonanych zadań
- Zarządzanie zespołami
- Konfiguracja zasad bonusów

## Technologie

- **100% Vanilla JavaScript** - bez frameworków czy bibliotek
- **Responsive Design** - działa na desktop i mobile
- **LocalStorage** - dane zapisywane lokalnie w przeglądarce
- **Mockowane dane** - gotowe przykładowe dane testowe

## Kod Źródłowy

Pełny kod źródłowy dostępny w folderze [`/prototype`](https://github.com/jakubciszak/family-plan/tree/main/prototype)

## Reset Danych

Aby zresetować dane do stanu początkowego:
1. Otwórz konsolę przeglądarki (F12)
2. Wykonaj: `localStorage.clear()`
3. Odśwież stronę
